# Projeto Prático: Bootstrap 5 - Landing Page

**Autor:** Arthur de Oliveira  
**Data:** 02/11/2026

## Descrição do Projeto
Este projeto consiste em uma Landing Page responsiva para um produto fictício chamado "IncluVision", um projeto de óculos inteligentes focado em recursos de acessibilidade. A página foi desenvolvida como requisito prático de conclusão do curso de Bootstrap 5.

## Tecnologias e Recursos Utilizados
A página foi construída com HTML5 e o framework CSS Bootstrap 5, cumprindo todos os requisitos da atividade:

* **Sistema de Grid:** Utilização intensiva de `.row` e `.col-*` (ex: `col-md-6`, `col-md-4`) para garantir responsividade em desktop, tablet e mobile.
* **Componentes do Bootstrap aplicados:**
  1. **Navbar (Aula #16):** Menu de navegação superior responsivo.
  2. **Cards (Aula #12):** Utilizados para apresentar as principais funcionalidades e inovações de software/hardware do produto.
  3. **Formulário (Aula #06):** Criado para captação de leads/contato na seção inferior da página.
  4. **Botões (Aula #07):** Calls to action (CTA) estilizados.
* **Estilização e Espaçamento:** Uso de classes de cores nativas (como `.bg-dark`, `.text-primary`), utilitários de margem e preenchimento (`.mt-5`, `.py-5`, `.mb-4`) e tipografia (`.display-4`, `.fw-bold`, `.lead`).
* **Imagens e Tabelas (Aulas #09 e #10):** Utilização da classe `.img-fluid` para imagem responsiva e criação de uma tabela estilizada (`.table-striped`, `.table-dark`) para apresentar as especificações técnicas do hardware.
